# iOS/iPadOS

{% hint style="info" %}
### Note

The SMS filtering and call blocking features offered by Cortex XDR are available only in iPhones. iPads do not support SMS messaging or cellular-based telephony, even when fitted with a SIM card.
{% endhint %}
