# Upgrade the Cortex XDR Agent

Support for upgrades depends on the agent type:

* Standard endpoints and persistent VDI—Upgrades are distributed from the Cortex XDR server. Follow the steps in the Administrator’s Guide for your license type.
* Non-persistent VDI and temporary sessions—Upgrades from the Cortex XDR server are not supported. To upgrade the agent, you must reinstall the agent on the golden image. For instructions see [Cortex XDR Agent for Virtual Environments and Desktops](cortex-xdr-agent-for-virtual-environments-and-desktops).
