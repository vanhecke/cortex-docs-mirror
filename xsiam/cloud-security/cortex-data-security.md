# Cortex Data Security

{% hint style="info" %}
This feature is included with a Cortex XSIAM Premium license. It is also included with any other Cortex XSIAM license that has the Cloud Posture Security or Cloud Runtime Security add-on.
{% endhint %}

Cortex Data Security is a comprehensive data security platform that discovers, classifies, protects, and governs sensitive data across your organization.

**What is Cortex Data Security?**

When you start managing your data assets in the cloud, this requires the implementation of comprehensive data security capabilities. The mission of Cortex Data Security is to provide you with such capabilities, in order to ensure complete visibility and real-time control over potential security risks to your data.

For more information, see the [Data Security Documentation](https://app.gitbook.com/o/r4DIGbR5VLvkZy3gAYsu/s/HfNuZNmWlqy9Bl7fETmL/).
