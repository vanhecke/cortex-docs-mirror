# Use an existing policy to create a new one

You can use an existing custom default cloud security policy to create a new one. To create a new cloud security policy using an existing policy:

1. Navigate to **Posture Management** → **Rules & Policies** → **Policies** → **Cloud Security**.
2. From the **Policies** page, there are two ways to access the option:
   * Right-click the entry and then select **Save as New.**
   * Click on the policy. Next, on the **Details** page, click the more options icon (⋮) and then select **Save as New.**
3. Modify the Policy Name, Description, and Labels fields as necessary.
4. Select the Rules that you would like to be alerted on:
   * All Matching Filter Criteria
   * Rules List
   * All Rules
5. Select the Scope that you would like to be alerted on:
   * Cloud Accounts
   * Asset Groups
   * All Cloud Assets
6. Click **Done** to save the new custom policy.
