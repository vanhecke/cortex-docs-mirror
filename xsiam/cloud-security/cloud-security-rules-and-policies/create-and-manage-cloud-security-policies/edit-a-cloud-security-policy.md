# Edit a cloud security policy

To edit a cloud security policy:

1. To edit a cloud security policy:
2. Navigate to **Posture Management** → **Rules & Policies** → **Policies** → **Cloud Security**.
3. From the **Policies** page, there are two ways to access the option:
   * Right-click the entry and then select **Edit.**
   * Click on the policy. Next, on the **Details** page, click the more options icon (⋮) and then select **Edit.**
4. Make the necessary changes on the policy **Details**, **Rules**, and **Scope** screens.
5. Click **Done** to save your changes.
