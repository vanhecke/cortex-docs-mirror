# Delete a custom cloud security rule

You can delete custom cloud security rules. For example, you may consider deleting a previously defined cloud security rule if it is generating too many false-positive issues.

To delete a custom cloud security rule:

1. Navigate to **Posture Management** → **Rules & Policies** → **Rules** → **Cloud Security**.
2. From the **Rules** page, there are two ways to access the option:
   1. Right-click the entry and then select **Delete.**
   2. Click on the policy. Next, on the **Details** page, click the more options icon (⋮) and then select **Delete.**
