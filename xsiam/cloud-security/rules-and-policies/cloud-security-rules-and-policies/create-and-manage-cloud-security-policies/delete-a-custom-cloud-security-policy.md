# Delete a custom cloud security policy

You can delete custom cloud security policies. To delete a custom cloud security policy:

1. Navigate to **Posture Management** → **Rules & Policies** → **Policies** → **Cloud Security**.
2. From the **Policies** page, there are two ways to access the option:
   1. Right-click the entry and then select **Delete.**
   2. Click on the policy. Next, on the **Details** page, click the more options icon (⋮) and then select **Delete.**
