# Cortex XSIAM - Analytics

The Cortex XSIAM Analytics engine enables Cortex XSIAM to analyze data from a variety of sensors and develop a baseline to raise analytics alerts when anomalies and malicious behaviors are detected.

{% hint style="warning" %}
### Prerequisite

Before Cortex XSIAM - Analytics can start to analyze your endpoint data, perform the following steps:

1. Configure Cortex XSIAM network parameters to monitor your internal networks.
2. Enable the Analytics Engine.
3. Make sure Cloud Identity Engine is set up.
4. Enable Identity Analytics.
{% endhint %}
