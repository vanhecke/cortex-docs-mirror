# Endpoint security

This section outlines how Cortex XSIAM, with its integration of the Cortex XDR agent, provides comprehensive protection for your endpoints. It details the key features and functionalities that enable you to prevent sophisticated attacks, rapidly detect and investigate threats, and automate response actions across all your endpoints, whether on-premises or remote.

{% hint style="info" %}
Requires one of the following licenses

* Cortex XSIAM Premium
* Cortex XSIAM Enterprise
* Cortex XSIAM NG-SIEM with the Cloud Runtime Security add-on or the Enterprise Runtime Security add-on
{% endhint %}
