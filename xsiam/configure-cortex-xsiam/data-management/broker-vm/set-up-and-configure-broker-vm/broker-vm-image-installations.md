# Broker VM image installations

Learn more about the Broker VM image types available that are compatible with your virtual machine (VM).

Before downloading, ensure that your virtual machine (VM) is compatible with one of the options below. To download the image, select Settings → Configurations → Data Broker → Broker VMs, click Add Broker, and select the applicable image you want to install:

| Infrastructure            | Image Type  | Broker Image Installation                                                                                                                                           |
| ------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Alibaba Cloud             | QCOW2       | [Set up Broker VM on Alibaba Cloud](broker-vm-image-installations/set-up-broker-vm-on-alibaba-cloud)                                                                |
| Amazon Web Services (AWS) | VMDK        | [Set up Broker VM on Amazon Web Services](broker-vm-image-installations/set-up-broker-vm-on-amazon-web-services)                                                    |
| Google Cloud Platform     | VMDK        | [Set up Broker VM on Google Cloud Platform (GCP)](broker-vm-image-installations/set-up-broker-vm-on-google-cloud-platform-gcp)                                      |
| KVM                       | QCOW2       | [Set up Broker VM on KVM using Ubuntu](broker-vm-image-installations/set-up-broker-vm-on-kvm-using-ubuntu)                                                          |
| Microsoft Azure           | VHD (Azure) | [Set up Broker VM on Microsoft Azure](broker-vm-image-installations/set-up-broker-vm-on-microsoft-azure)                                                            |
| Microsoft Hyper-V 2012    | VHD         | Hyper-V 2012 or later [Set up Broker VM on Microsoft Hyper-V](broker-vm-image-installations/set-up-broker-vm-on-microsoft-hyper-v)                                  |
| Nutanix Hypervisor        | QCOW2       | Nutanix AHV 10.3 or later [Set up Broker VM on Nutanix Hypervisor](broker-vm-image-installations/set-up-broker-vm-on-nutanix-hypervisor)                            |
| VMware ESXi               | OVA         | VMware ESXi 6.5 or later [Set up Broker VM on VMware ESXi using vSphere Client](broker-vm-image-installations/set-up-broker-vm-on-vmware-esxi-using-vsphere-client) |
