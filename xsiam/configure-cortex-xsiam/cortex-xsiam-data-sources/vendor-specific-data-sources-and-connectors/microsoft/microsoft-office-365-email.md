# Microsoft Office 365 (email)

You can configure collecting Microsoft Office 365 email metadata using a Standard Collector:

| Collection Method                       | Description                                                                                                                       |
| --------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- |
| Standard Collector overview             | Forward email metadata through Microsoft Graph API to Cortex XSIAM from Microsoft Office 365 using the Microsoft 365 data source. |
| Link to Standard Collector instructions | [Ingest logs and data from Microsoft 365](microsoft-office-365-email/ingest-logs-and-data-from-microsoft-365)                     |
