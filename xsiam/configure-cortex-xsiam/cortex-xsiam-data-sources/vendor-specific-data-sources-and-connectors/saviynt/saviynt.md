# Saviynt

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).
{% endhint %}

This sub-capability is available with any active Cortex XSIAM license.

Saviynt Enterprise Identity Cloud (EIC) is an AI-driven, cloud-native identity security platform that unifies Identity Governance and Administration (IGA). It manages and secures user and non-human access across hybrid IT environments to help organizations reduce risk and meet compliance mandates. This connector collects Saviynt EIC audit logs.

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* [SaviyntEICEventCollector](https://xsoar.pan.dev/docs/reference/integrations/saviynt-eic-event-collector): Collector for Saviynt Enterprise Identity Cloud (EIC) audit logs using Analytics Runtime Control V2.

To configure this connector, follow the steps outlined in the configuration wizard.
