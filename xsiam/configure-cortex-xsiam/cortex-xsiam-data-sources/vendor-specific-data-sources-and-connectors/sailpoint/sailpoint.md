# SailPoint

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace)..
{% endhint %}

This sub-capability is available with any active Cortex XSIAM license.

SailPoint Identity Security takes the complexity out of identity, making it intuitive for IT staff to configure and manage while enabling business users with the access they need. This connector collects events from SailPoint IdentityNow to drive identity-aware security practices.

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* [SailPointIdentityNowEventCollector](https://xsoar.pan.dev/docs/reference/integrations/sail-point-identity-now-event-collector): This is the SailPoint IdentityNow event collector integration for Cortex XSIAM.

To configure this connector, follow the steps outlined in the configuration wizard.
