# Google Kubernetes Engine

{% hint style="info" %}
**Note**

It's also possible to use a Custom - Filebeat based Collector to ingest logs related to file activity on your endpoints and servers without using the Cortex XDR agent. For more information, see [Elasticsearch Filebeat](../elastic/elasticsearch-filebeat).
{% endhint %}
