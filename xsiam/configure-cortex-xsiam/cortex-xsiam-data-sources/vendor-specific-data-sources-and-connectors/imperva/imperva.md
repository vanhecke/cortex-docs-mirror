# Imperva

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).
{% endhint %}

This sub-capability is available with any active Cortex XSIAM or Cortex AgentiX license.

Integrate with Imperva security products. Imperva Skyfence is a Cloud Access Security Broker (CASB) that provides visibility and control over cloud apps. Imperva WAF (SecureSphere) protects web applications from cyber attacks. Imperva Incapsula (Cloud WAF) manages sites and IPs.

This connector includes the following sub-capabilities:

* [Imperva Skyfence](https://xsoar.pan.dev/docs/reference/integrations/imperva-skyfence): Provides visibility and control over cloud apps.
* [Imperva WAF](https://xsoar.pan.dev/docs/reference/integrations/imperva-waf): Manages IP groups and web security policies.
* [Incapsula](https://xsoar.pan.dev/docs/reference/integrations/incapsula): Manages sites and IPs.

Follow the configuration wizard to configure this connector.
