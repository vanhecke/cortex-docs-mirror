# HTTP log collector

You can configure collecting any vendor logs over HTTP with a Custom - HTTP based Collector in a Raw, JSON, CEF, or LEEF format.

| Collection Method                                             | Description                                                                                                                |
| ------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Custom - HTTP based Collector (standard data source) overview | Forward any vendor logs over HTTP in a Raw, JSON, CEF, or LEEF format to Cortex XSIAM using the Custom - HTTP data source. |
| Link to standard data source instructions                     | [Set up an HTTP log collector to receive logs](http-log-collector/set-up-an-http-log-collector-to-receive-logs)            |
