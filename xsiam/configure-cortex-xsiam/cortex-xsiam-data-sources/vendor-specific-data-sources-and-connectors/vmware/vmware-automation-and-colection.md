# VMware Automation and Colection

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).
{% endhint %}

This sub-capability is available with any active Cortex XSIAM or Cortex AgentiX license.

Manage VMware products: administer virtual machines and ESXi hosts through vCenter, hunt and respond to endpoint threats with Carbon Black EDR, and search and manage enrolled devices with Workspace ONE UEM (AirWatch MDM).

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* [VMware](https://xsoar.pan.dev/docs/reference/integrations/v-mware): VMware vCenter server is a centralized management application that lets you manage virtual machines and ESXi hosts centrally.
* [VMware Carbon Black EDR v2](https://xsoar.pan.dev/docs/reference/integrations/v-mware-carbon-black-edr-v2):
* [VMware Workspace ONE UEM (AirWatch MDM)](https://xsoar.pan.dev/docs/reference/integrations/v-mware-workspace-one-uem-air-watch-mdm):

To configure this connector, follow the steps outlined in the configuration wizard.
