# iZOOlogic

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).
{% endhint %}

This sub-capability is available with any active Cortex XSIAM, Cortex Cloud Posture Security with the Application Security Posture Management (ASPM) module, Cortex Cloud, Cortex Cloud Runtime Security, Cortex XDR, or Cortex AgentiX license with the Attack Surface Management (ASM), Exposure Management, or Threat Intel Management (TIM) add-on.

iZOOlogic is a brand protection and threat management platform. This connector fetches and manages issues from iZOOlogic, enabling automated ingestion, issue creation, and advanced filtering across threat types including phishing, brand abuse, malware, and more.

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* iZOOlogic

To configure this connector, follow the steps outlined in the configuration wizard.
