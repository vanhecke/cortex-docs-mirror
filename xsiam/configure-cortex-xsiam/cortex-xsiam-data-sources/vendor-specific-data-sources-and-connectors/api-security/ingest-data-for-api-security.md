# Ingest data for API security

Configure the settings in both Cortex XSIAM and your cloud service provider to retrieve and collect API data for further analysis by Cortex's comprehensive [API security](../../../../cloud-security/overview/secure-your-api-landscape/gain-visibility-and-assess-risk-of-api-endpoints) capabilities that provides a transparent view of API traffic, helping to identify potential security threats.
