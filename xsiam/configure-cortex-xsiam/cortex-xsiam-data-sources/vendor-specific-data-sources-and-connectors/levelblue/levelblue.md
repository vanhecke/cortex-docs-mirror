Trustwave Secure Email Gateway (SEG) is a secure messaging solution that protects businesses and users from email-borne threats, including phishing, blended threats, and spam. It also delivers improved policy enforcement and data leakage prevention.

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* [trustwave secure email gateway](https://xsoar.pan.dev/docs/reference/integrations/trustwave-secure-email-gateway)

To configure this connector, follow the steps outlined in the configuration wizard.
