# OpenPhish

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).

This sub-capability is available with any active Cortex XSIAM or Cortex AgentiX license.

OpenPhish uses proprietary Artificial Intelligence algorithms to automatically identify zero-day phishing sites and provide comprehensive, actionable, real-time threat intelligence.

This connector includes the following sub-capabilities (Marketplace integrations link to PAN DEV for more information):

* [OpenPhish\_v2](https://xsoar.pan.dev/docs/reference/integrations/open-phish-v2): OpenPhish uses proprietary Artificial Intelligence algorithms to automatically identify zero-day phishing sites and provide comprehensive, actionable, real-time threat intelligence.
