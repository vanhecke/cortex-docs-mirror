# Kafka

{% hint style="warning" %}
**Important**

This connector is only available for tenants that onboarded after July 26, 2026. For tenants that onboarded before this date, use Marketplace to access the standalone integration. For more information, see [Marketplace](../../../marketplace).
{% endhint %}

This connector is available with any active Cortex XSIAM or Cortex AgentiX license.

Kafka is an open-source distributed streaming platform. Use this connector to manage messages and partitions, and fetch Kafka messages to create issues.

* [KafkaV3](https://xsoar.pan.dev/docs/reference/integrations/kafka-v3): Kafka integration.

Follow the configuration wizard to configure this connector.
