| Collection Method                                 | Description                                                                                           |
| ------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| Standard Collector overview                       | Forward logs from the ServiceNow CMDB database to Cortex XSIAM using the ServiceNow CMDB data source. |
