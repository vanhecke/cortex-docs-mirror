# Amazon Web Services cloud onboarding

Cortex XSIAM onboarding is the process of connecting your Amazon Web Services (AWS) cloud environment to Cortex XSIAM so it can continuously monitor, scan, and protect your cloud resources. This process establishes secure, least-privilege access for comprehensive security monitoring and threat detection. You gain visibility into your cloud infrastructure and can choose to enable security capabilities such as vulnerability scanning, data protection, and compliance monitoring.

The onboarding process provisions the infrastructure in your AWS environment required to monitor, secure, and analyze your cloud resources. The sections below describe the available capabilities, the resources created, the security model, and the step-by-step onboarding process.
