# Onboard Alibaba Cloud

Use the cloud onboarding wizard to integrate an Alibaba Cloud environment with Cortex XSIAM. The onboarding wizard requires minimal configuration to set up the integration. You can optionally define the scope of the Alibaba regions and have tags automatically added to any new resources created by Cortex XSIAM.

Cortex XSIAM generates a Terraform authentication template based on the configuration settings. The authentication template grants required permissions to Cortex XSIAM. Execute the authentication template in Alibaba Cloud and then manually connect the cloud instance to complete the onboarding process.
