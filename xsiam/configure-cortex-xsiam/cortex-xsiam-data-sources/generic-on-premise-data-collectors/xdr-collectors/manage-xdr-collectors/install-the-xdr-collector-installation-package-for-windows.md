# Install the XDR Collector installation package for Windows

A standard XDR Collector installation for Windows is intended for standard physical collector machines or persistent virtual collector machines. You can perform the Windows installation for the XDR Collectors using the [MSI](install-the-xdr-collector-installation-package-for-windows/install-the-xdr-collector-on-windows-using-the-msi) or [Msiexec](install-the-xdr-collector-installation-package-for-windows/install-the-xdr-collector-on-windows-using-msiexec).
