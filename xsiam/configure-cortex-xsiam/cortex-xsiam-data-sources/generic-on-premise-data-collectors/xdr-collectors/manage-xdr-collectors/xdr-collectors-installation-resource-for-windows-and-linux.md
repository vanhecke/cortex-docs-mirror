# XDR Collectors installation resource for Windows and Linux

The following table provides important information about the XDR Collectors installation for Windows and Linux.

| Installation component | Default path                                                                                                                                                                                          | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Related files/Services                                                                                                                                                                                                                                                                                            |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Installation folder    | <ul><li><strong>Windows</strong>:<code>%PROGRAMFILES%\Palo Alto Networks\XDR Collector</code></li><li><strong>Linux</strong>:<code>/opt/paloaltonetworks/xdr-collector</code></li></ul>               | The default installation path for the XDR Collector. Contains all Program Core files and executables.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | <ul><li><p><strong>Windows</strong></p><ul><li>Service name: <code>XDR Collector</code></li><li>Process name: <code>xdrcollectorsvc.exe</code></li></ul></li><li><p><strong>Linux</strong></p><ul><li>Service name: <code>xcd</code></li><li>Process name: <code>xdr-collector.service</code></li></ul></li></ul> |
| Logs                   | <ul><li><strong>Windows</strong>:<code>%PROGRAMDATA%\XDR Collector\logs</code></li><li><strong>Linux</strong>:<code>/opt/paloaltonetworks/xdr-collector/logs</code></li></ul>                         | <ul><li><strong>Windows</strong>: Contains the XDR Collector application Log, the Filebeat application log, and the Winlogbeat application log. Indicates information, warnings, and errors related to the XDR Collector application.</li><li><strong>Linux</strong>: Contains the XDR Collector application Log as well as the Filebeat application log. Indicates information, warnings, and errors related to the XDR Collector application.</li></ul><p>Contains the XDR Collector application Log as well as the Filebeat application log. Indicates information, warnings, and errors related to the XDR Collector application.</p> | <ul><li><p><strong>Windows</strong></p><ul><li><code>scouter.log</code></li><li><code>filebeat</code></li><li><code>winlogbeat</code></li></ul></li><li><p><strong>Linux</strong></p><ul><li><code>scouter.log</code></li><li><code>filebeat</code></li></ul></li></ul>                                           |
| Configuration          | <ul><li><strong>Windows</strong>:<code>%PROGRAMFILES%\Palo Alto Networks\XDR Collector\config</code></li><li><strong>Linux</strong>:<code>/opt/paloaltonetworks/xdr-collector/config</code></li></ul> | Contains the XML configuration file of the XDR Collector for both Windows and Linux. Any change in this XML configuration file is saved to the XDR Collector database and the settings are taken from this file. ### Note In some circumstances, such as after an XDR Collectors upgrade, the configured settings in the XML configuration file can be erased. Yet, this won't affect the saved settings in the XDR Collectors database.                                                                                                                                                                                                  | For both Windows and Linux, the file name is `XDR_Collector.xml`.                                                                                                                                                                                                                                                 |
| Persistence            | <ul><li><strong>Windows</strong>:<code>%PROGRAMDATA%\XDR Collector\OSPersistence</code></li><li><strong>Linux</strong>:<code>/etc/panw/OSPersistence/</code></li></ul>                                | Contains the Operating System persistence file for the XDR Collector, which issued as part of the registration process.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | For both Windows and Linux, the file name is `.scouter.json`.                                                                                                                                                                                                                                                     |
