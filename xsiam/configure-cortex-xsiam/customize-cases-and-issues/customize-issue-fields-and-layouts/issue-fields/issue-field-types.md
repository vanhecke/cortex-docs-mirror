# Issue field types

You can create the following types of issue fields.

<table><thead><tr><th width="173.5">Field</th><th>Description</th></tr></thead><tbody><tr><td>Boolean</td><td><p>True or False</p><ul><li>Incoming values <strong><code>0</code></strong>, <strong><code>false</code></strong>, and <strong><code>False</code></strong> are treated as False.</li><li>Incoming values <strong><code>true</code></strong>, <strong><code>True</code></strong>, or any number besides 0 are treated as True.</li><li>Other values are treated as null.</li></ul></td></tr><tr><td>Date picker</td><td><p>Adds the date to the field.</p><p>Supported time formats for validation are ISO 8601 and Epoch. Other values are treated as null.</p><div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>You cannot set filters, starring rules, automation rules, layout rules, or issue exclusions based on the values in custom timestamp fields.</p></div></td></tr><tr><td>Grid (table)</td><td><p>Include an interactive, editable grid as a field. For details, see Create a grid field for an issue.</p><div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>When a grid field is shown in the Issues table, if there are values in the field, they do not display in the table. Instead, the column shows Data Available.</p></div></td></tr><tr><td>HTML</td><td><p>Create and view HTML content.</p><div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>When an HTML field is shown in the Issues table, if there is a value in the field, it does not display in the Issues table. Instead, the column shows Data Available.</p></div><div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>The following HTML tags are not permitted: <code>blockquote</code>, <code>del</code>, <code>dd</code>, <code>div</code>, <code>dl</code>, <code>dt</code>, <code>fieldset</code>, <code>form</code>, <code>h1</code>, <code>h2</code>, <code>h3</code>, <code>h4</code>, <code>h5</code>, <code>h6</code>, <code>hr</code>, <code>iframe</code>, <code>ins</code>, <code>li</code>, <code>math</code>, <code>noscript</code>, <code>ol</code>, <code>pre</code>, <code>p</code>, <code>script</code>, <code>style</code>, <code>table</code>, <code>ul</code>, <code>address</code>, <code>article</code>, <code>aside</code>, <code>canvas</code>, <code>details</code>, <code>dialog</code>, <code>figcaption</code>, <code>figure</code>, <code>footer</code>, <code>header</code>, <code>hgroup</code>, <code>main</code>, <code>nav</code>, <code>output</code>, <code>progress</code>, <code>section</code>, <code>video</code>.</p></div><div data-gb-custom-block data-tag="hint" data-style="warning" class="hint hint-warning"><p>The following CSS tags are not permitted: <code>background-color</code>, <code>text-align</code>, <code>font-size</code>, <code>font-family</code>, <code>font-weight</code>, <code>color</code>, <code>line-height</code>, <code>border-style</code>, <code>border</code>, <code>page-break-inside</code>, <code>tablelayout</code>, <code>padding</code>, <code>background-size</code>, <code>word-break</code>, <code>width</code>, <code>height</code>, <code>-ms-text-size-adjust</code>, <code>-webkit-text-size-adjust</code>.</p></div></td></tr><tr><td>Long text</td><td><ul><li>Long text is analyzed and tokenized, and entries are indexed as individual words, enabling you to perform advanced searches and use wildcards.</li><li>Long text fields cannot be sorted and cannot be used Case is insensitive.</li></ul></td></tr><tr><td>Markdown</td><td><p>Add markdown-formatted text as a Template which is displayed to users in the field. Default is 0.</td></tr><tr><td>Short Text</td><td><ul><li>Short text is treated as a single unit of text, and is not indexed by word.
