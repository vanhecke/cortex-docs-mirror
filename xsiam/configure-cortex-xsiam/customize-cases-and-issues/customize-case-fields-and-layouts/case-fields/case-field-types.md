# Case field types

You can create the following types of case fields:

<table><thead><tr><th width="154">Field</th><th>Description</th></tr></thead><tbody><tr><td>Boolean</td><td><p>True or False</p><ul><li>Incoming values <strong><code>0</code></strong>, <strong><code>false</code></strong>, and <strong><code>False</code></strong> are treated as <strong>False</strong>.</li><li>Incoming values <strong><code>true</code></strong>, <strong><code>True</code></strong>, or any number besides 0 are treated as <strong>True</strong>.</li><li>Other values are treated as null.</li></ul></td></tr><tr><td>Date picker</td><td><p>Adds the date to the field.</p><p>Supported time formats for validation are ISO 8601 and Epoch. Other values are treated as null.</p><div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p><strong>Note</strong></p><p>You cannot set filters, starring rules, automation rules, layout rules, or issue exclusions based on the values in custom timestamp fields.</p></div></td></tr><tr><td>Grid (table)</td><td><p>Include an interactive, editable grid as a field. For details, see <a href="create-a-grid-field-for-a-case">Create a grid field for a case</a>.</p><div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p><strong>Note</strong></p><p>When grid field is shown in the <strong>Cases</strong> table, if there are values in the field, they do not display in the <strong>Cases</strong> table. Instead, the column shows <strong>Data Available</strong>.</p></div></td></tr><tr><td>HTML</td><td><p>Create and view HTML content.</p><div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p><strong>Note</strong></p><p>When an HTML field is shown in the <strong>Issues</strong> table, if there is a value in the field, it does not display in the <strong>Cases</strong> table. Instead, the column shows <strong>Data Available</strong>.</p></div></td></tr><tr><td>Long text</td><td><ul><li>Long text is analyzed and tokenized, and entries are indexed as individual words, enabling you to perform advanced searches and use wildcards.</li><li>Long text fields cannot be sorted and cannot be used in graphical dashboard widgets.</li><li>While editing a long text field, pressing enter will create a new line. Case is insensitive.</li></ul></td></tr><tr><td>Markdown</td><td><p>Add markdown-formatted text as a <strong>Template</strong> which is displayed to users in the field. Markdown lets you add basic formatting to text to provide a better end-user experience.</p><div data-gb-custom-block data-tag="hint" data-style="info" class="hint hint-info"><p><strong>Note</strong></p><p>When a Markdown field is shown in the <strong>Cases</strong> table, if there is a value in the field, it does not display in the <strong>Cases</strong> table. Instead, the column shows <strong>Data Available</strong>.</p></div></td></tr><tr><td>Multi select / Array</td><td><p>Includes two options:</p><ul><li>Multi select from a pre-filled list.</li><li>An empty array field for the user to add one or more values as a comma-separated list.</li></ul><p>In the <strong>Basic Settings</strong> section, enter a comma-separated list of values.</p></td></tr><tr><td>Number</td><td>Can contain any number. Default is 0.</td></tr><tr><td>Short Text</td><td><ul><li>Short text is treated as a single unit of text, and is not indexed by word. Advanced search, including wildcards, is not supported.</li><li>Short text fields are case insensitive.</li><li>While editing a short text field, pressing enter will save and close.</li><li>Recommended use is one word entries. Examples: username, email address, etc.</li></ul></td></tr><tr><td>Single select</td><td>Select one from a list of options. Add a list of comma-separated values. By default, the first value is used, unless the checkbox for <strong>Use first as default</strong> is cleared.</td></tr><tr><td>SLA</td><td><p>SLA can be used to trigger a notification when the status affecting the SLA of a case changes. In this example, if the SLA is breached an email is sent to the owner's supervisor.</p><p>For more information on SLAs, see <a href="../../create-slas-for-issue-resolution/create-case-timers-and-slas">Create case timers and SLAs</a>.</p></td></tr><tr><td>Timer</td><td>Timer fields enable you to view how much time has passed since the timer was started and how much time remains until the timer times out. You can also configure a script to run when a timer times out.</td></tr><tr><td>URL</td><td>Contains a URL.</td></tr></tbody></table>

{% hint style="info" %}
### Note

If you make changes to case fields you can update the context data by running a playbook, script, or command. For more information, see [Update case fields](update-case-fields).

To update dynamic custom case fields, such as SLA and Timer fields, see [Update case timer and SLA fields](../../create-slas-for-issue-resolution/create-case-timers-and-slas/update-case-timer-and-sla-fields).
{% endhint %}
