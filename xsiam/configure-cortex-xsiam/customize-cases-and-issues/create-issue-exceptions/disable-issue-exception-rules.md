# Disable issue exception rules

Disabling an issue exception rule turns the exception rule off so that it no longer creates issue exceptions.

{% hint style="info" %}
You cannot delete issue exception rules. You can disable them so that they no longer create issues.

You cannot re-enable an issue exception rule after it has been disabled.
{% endhint %}

1. Navigate to Settings → Exceptions → Configuration → Exception Rules.
2. Right-click a rule and select Disable.
