# View excepted issues

You can view excepted issues by sorting or filtering the Issues page.

1. Navigate to Cases & Issues → Issues.
2. Filter the list of issues by Excepted = Yes to see the complete list of excepted issues.
3. View the Remaining Exception Period field to see how much time is left until the exception expires.<br>
