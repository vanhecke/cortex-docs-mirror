# Supported web browsers

Cortex XSIAM supports the following web browsers:

| Browser        | Version        |
| -------------- | -------------- |
| Chrome         | 95.x and later |
| Firefox        | 93.x and later |
| Safari         | 13.x and later |
| Microsoft Edge | Latest version |
| Prisma Browser | Latest version |
