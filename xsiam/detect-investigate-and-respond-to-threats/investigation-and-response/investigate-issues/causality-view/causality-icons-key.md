In this example, a NGFW alert was triggered on a TCP Protocol that called a remote IP address, that created an unknown process.

![Example\_NGFW\_alert.png](https://2786854933-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FAEIjuYE3RXcIfmuQnBbm%2Fuploads%2Fgit-blob-ef10941e83826ddb7498d903c6796c3ef7d6921a%2Ff0db7947a9c02b1997ad7773e3a2ac6b6121ad6c17a128a6d0f52ad8fb769caf.png?alt=media)

In this example, the highlighted process node represents the real parent that executed the process. Click on the node for more details about the parent process. The pen icon on the first process nodes indicates that this process is "last actor". The syringe icon on the last process node indicates that this process is an "injected node".

![Example\_starting\_process.png](https://2786854933-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FAEIjuYE3RXcIfmuQnBbm%2Fuploads%2Fgit-blob-d33c1bd748480f2bf905e751e7005c72fef211bf%2F64402cff61a49d854774a9d6696a231934d9ede6156b04b39383afcb7c4a8b49.png?alt=media)
