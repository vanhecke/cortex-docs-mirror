# Export issue details to a file

To archive, continue investigation offline, or parse issue details, you can export issues to a tab-separated values (TSV) file:

1. From the **Issues** page, adjust the filters to identify the issues you want to export.
2.  When you are satisfied with the results, click the download icon (![download-to-file-icon.png](https://2786854933-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FAEIjuYE3RXcIfmuQnBbm%2Fuploads%2Fgit-blob-f4f5235ac4953f5a4ab016940598787b61abca0f%2F304142ca85a8f4d658180147d4863d3896a9bca20d71cb7113b56d92579c5df8.png?alt=media)).

    The icon is grayed out when there are no results.

    Cortex XSIAM exports the filtered result set to the TSV file.

{% hint style="info" %}
To ensure fast, reliable downloads, you can export a maximum of 50k issues per export.
{% endhint %}
