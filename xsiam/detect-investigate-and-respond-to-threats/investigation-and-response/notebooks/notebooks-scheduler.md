# Notebooks scheduler

Ensure automatic data enrichment by scheduling Notebook jobs to run immediately or on a schedule.

1.  In the **Notebooks** window, on the left sidebar tab, right-click the file you want to run and select **Create Notebook Job**.

    ![notebook-job.png](https://2786854933-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2FAEIjuYE3RXcIfmuQnBbm%2Fuploads%2Fgit-blob-f5af26e30b019cab8ac8d696d41caa8621854729%2F6938d31e022d0ea0487ebe9a9f33554af8780597b1677da55035a8bb5e0fe81c.png?alt=media)
2. In the **Create Job** page, update the required parameters, such as the job name and output formats.
3. Select whether to run the job now or on a schedule.

The results of the scheduled job are reflected in the related rules as soon as the job runs.
