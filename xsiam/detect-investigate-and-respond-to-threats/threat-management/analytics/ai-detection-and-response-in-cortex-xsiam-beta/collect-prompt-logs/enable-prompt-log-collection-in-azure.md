# Enable prompt log collection in Azure

The following steps are necessary to enable prompt log collection in Microsoft Azure:

1. [Configure the Azure Event Hub collection](enable-prompt-log-collection-in-azure/configure-the-azure-event-hub-collection-in-cortex-xsiam).
2. [Set up prompt logging in Azure](enable-prompt-log-collection-in-azure/set-up-prompt-logging).
3. [Configure logging of HTTP data](enable-prompt-log-collection-in-azure/log-http-data).
4. [Configure diagnostic settings](enable-prompt-log-collection-in-azure/configure-diagnostic-settings).
