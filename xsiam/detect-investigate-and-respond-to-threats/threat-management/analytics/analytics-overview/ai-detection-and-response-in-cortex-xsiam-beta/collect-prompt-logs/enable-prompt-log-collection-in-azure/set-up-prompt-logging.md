# Set up prompt logging

1. In the Azure portal, [create a new Azure API Management instance](https://learn.microsoft.com/en-us/azure/api-management/get-started-create-service-instance).
2. [Create and deploy an Azure OpenAI resource](https://learn.microsoft.com/en-us/azure/ai-services/openai/how-to/create-resource?pivots=web-portal).
3. [Import an Azure OpenAI API](https://learn.microsoft.com/en-us/azure/api-management/azure-openai-api-from-specification).
