# Generate YAML from Python

You can use the demisto-sdk [generate-yml-from-python](https://app.gitbook.com/s/nozw5MT5S8KZD2eF8roV/demisto-sdk-guide/demisto-sdk-commands/generate-yml-from-python) command to create a YAML file from your Python code. Currently, only generation for integrations is supported.

For more information and examples, see the Demisto SDK guide.
