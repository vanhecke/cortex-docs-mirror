# OpenAPI (Swagger) Codegen

You can generate a Cortex XSIAM integration package (YAML and Python files) using the [openapi-codegen](https://app.gitbook.com/s/nozw5MT5S8KZD2eF8roV/demisto-sdk-commands/openapi-codegen) command in the Demisto SDK. The integration can be used immediately after after you generate it.
