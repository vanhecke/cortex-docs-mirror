# Generate Integration Python Code from JSON

You can use the demisto-sdk [generate-integration](https://app.gitbook.com/s/nozw5MT5S8KZD2eF8roV/demisto-sdk-guide/demisto-sdk-commands/generate-integration) command to generate a Cortex XSIAM integration from an integration config JSON file. The JSON config file can be generated from a Postman collection via the demisto-sdk [postman-codegen](https://app.gitbook.com/s/nozw5MT5S8KZD2eF8roV/demisto-sdk-guide/demisto-sdk-commands/postman-codegen) command.
