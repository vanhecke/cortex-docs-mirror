# Postman code generator

You can use the demisto-sdk [postman-codegen](https://app.gitbook.com/s/nozw5MT5S8KZD2eF8roV/demisto-sdk-guide/demisto-sdk-commands/postman-codegen) command to generate an integration (YAML file) from a Postman Collection v2.1. Note the generated integration is in the YAML format.
