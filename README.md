# Cortex documentation mirror

A daily copy of the [Palo Alto Cortex documentation portal](https://cortex-docs.paloaltonetworks.com).
Each commit is one day's change to the official documentation.

Every `.md` file here is the portal's own markdown, unmodified — YAML front
matter, GitBook block macros (`{% hint %}`) and absolute image URLs are all left
as published. Cross-references are portal-relative and do not resolve inside this
repository; they are kept verbatim so a diff only ever shows an upstream change.

Pages sit at their portal path, under a directory named for the book rather than
for the portal section, so a section that is republished per product version
diffs its pages in place instead of moving all of them. `.meta/<book>.json`
records each book's navigation tree and the section it came from.
